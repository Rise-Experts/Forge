# Observability

Retinue exposes structured run lifecycle information, usage accounting, and an OpenTelemetry adapter. It does not include a hosted dashboard: export traces, metrics, and logs to your own observability backend.

Use run IDs and request IDs to correlate API, worker, provider, and tool activity. Usage records model consumption as it occurs; tool and run events provide the durable operational trail.
