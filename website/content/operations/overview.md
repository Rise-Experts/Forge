# Operations

Retinue records durable run events, supports reconnectable streams, and provides conformance, security, and release checks in this repository.

Start with [Troubleshooting](../troubleshooting) for practical failures. For deployment and recovery, read [Run Retinue in production](../production/overview) and [Durable runtime](../concepts/durable-runtime). The deeper operational design—including retention, load testing, and release criteria—lives in [Specifications](/specifications/).
