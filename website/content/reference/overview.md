# Reference

Use guides to learn the platform and reference pages to verify an exact public contract.

| Reference | Use it for |
|---|---|
| [Package surface](package-surface) | `@forge/agentkit`, public subpaths, and adapter boundaries |
| [Client package surface](client-surface) | `@forge/react` hooks and client state |
| [Generated API](/api/) | Exported types, functions, and their signatures |
| [Configuration](../getting-started/configuration) | Runtime configuration and environment variables |

The root package intentionally exports a small set of runtime values. Specialized capabilities live at documented subpaths such as `@forge/agentkit/tools`, `@forge/agentkit/flows`, and `@forge/agentkit/server`.
